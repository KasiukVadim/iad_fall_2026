# Модель, параметры и методы

## Maxwell IVP

В нормированных единицах: dD/dt=curl H, dH/dt=−curl(D/ε). D=εE, B=H, J=0, ρ=0. Для ε(x)>0 энергия W=½∫(D·D/ε+H·H)dV. Периодические границы обнуляют поверхностный поток. Дискретный центральный curl самосопряжён в периодическом скалярном произведении, отдельные центральные производные кососопряжённы. Поэтому пространственная полудискретизация сохраняет энергию. RK4 вносит малую временную ошибку.

div(curl F)=0 выполняется дискретно, потому что центральные производные по разным координатам коммутируют. Начальные D=(0,cos(2πx),0), H=(0,0,cos(2πx)) удовлетворяют div=0. E внутри включения определяется через D/ε, поэтому начальные E в двух IVP различаются внутри сферы. Разность E_total−E_homogeneous — возмущение двух начальных задач с одинаковыми D,H; это не определение исходящего рассеянного поля от заданной падающей волны.

Область [0,1)³. ε(x)=1+1.1 exp[−(r/0.14)^8], центр (0.5,0.5,0.5). Основная сетка 24³, время 0.65, шагов 160. Нормированные длины/время не задают одновременно оптическую и RFID-шкалу; для реальных единиц выбираются L0 и T0=L0/c0.

Однородный эталон Ey=Hz=cos[2π(x−t)]. Ошибка RMSE считается по всей 3D-сетке. Уточнение n=12,24,48 с steps=8n сохраняет отношение dt/h; O(h²) доминирует над O(dt⁴).

## Модель Ми

x=ka, m=n_sphere/n_background; в проекте background=vacuum. ψ_n(z)=z j_n(z), ξ_n(z)=z[j_n(z)+i y_n(z)].

 a_n=[m ψ_n(mx) ψ'_n(x)−ψ_n(x) ψ'_n(mx)]/[m ψ_n(mx) ξ'_n(x)−ξ_n(x) ψ'_n(mx)]

 b_n=[ψ_n(mx) ψ'_n(x)−m ψ_n(x) ψ'_n(mx)]/[ψ_n(mx) ξ'_n(x)−m ξ_n(x) ψ'_n(mx)]

Qsca=2/x² Σ(2n+1)(|a_n|²+|b_n|²). N=ceil(x+4 x^(1/3)+2). Реализация предназначена для небольших положительных real m,x (проверенный диапазон x=0.01…2); не претендует на устойчивость для крайне больших x или сильно поглощающих сред.

Рэлей: Q_R=(8/3)x⁴ |(m²−1)/(m²+2)|². Ошибка |Q_R−Q_M|/Q_M. Оптические данные n(λ) преобразуются в ε_r=n² только в прозрачном немагнитном режиме. Это вариация материала, не подгонка радиоантенны.

## Reader/tag и параметры

r_reader=0.04 m, r_tag=0.015 m, d=0.04 m; один виток, воздух. M из двойного интеграла Неймана; нормаль tag поворачивается вокруг x. Проверяются взаимность M12=M21, нулевая связь при 90° для соосного центра, сходимость квадратуры.

L=[L1,M;M,L2], L1=1 μH, L2=0.5 μH. R1=2 Ω, R2=4 Ω. f=13.56 MHz, Cj=1/[(2πf)²Lj], Vs=cos(2πft) V. State=(q1/C1,q2/C2,i1,i2), нулевое начальное состояние. Матрица L положительна при M²<L1L2; иначе предсказание запрещено.

Наблюдение i2(t), t=0…2 μs, 501 точка. σ=0.01 max|i2_true|, независимый Gaussian шум, seed=20261029. Истина генерируется с rtol=1e−10, fit использует rtol=2e−8. Каждая третья точка held out; наблюдения между train и held out принадлежат одному переходному процессу.

θ=(M/1 nH,R2/1 Ω). Начальная точка (12,6), bounds ([0.1,0.5],[100,15]); L,C,R1,Vs известны. Взвешенный least squares: r=(i_model−i_obs)/σ. Положительное M выбрано ориентацией намотки; magnitude-only измерения могут терять знак. Оценивается численный rank Jacobian; доверительные интервалы и устойчивость к model mismatch в текущую работу не включены.

## Смешанная модель

M_hybrid=M_geometry(d,tilt)+ΔM(features). Затем применяется та же RLC-динамика. ΔM может быть регрессией/нейросетью; нулевая функция даёт baseline. Предстоит обучать поправку на независимых измерениях, проверять новые расстояния/материалы и физические ограничения.
